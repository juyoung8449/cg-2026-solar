```` GitHub 저장소의 **Settings → Pages**에서 배포를 설정한 뒤 사이트를 새로고침하세요. 그래도 빈 화면이면 개발자 도구(**⌥⌘I → Console**)에서 오류를 확인하세요. `inspection-controls.js`의 파일명과 경로는 대소문자까지 정확히 일치해야 합니다.
