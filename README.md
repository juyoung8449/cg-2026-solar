# 나만의 태양계

## 내가 만들고 싶은 항성계
어두운 우주 공간을 배경으로 하여 나만의 태양계를 표현하고 싶었다. 실제 태양계에서 영감을 받되, 앞으로 행성과 별 등을 추가하여 나만의 항성계로 발전시키고 싶다.

## 실행 방법
GitHub Pages에서 공개된 URL에 접속하면 실행할 수 있다. WebGL2를 지원하는 브라우저에서 확인하였다.

## 사용한 Copilot 프롬프트
"WebGL2를 사용해서 브라우저 전체 화면에 우주 공간을 표현하는 간단한 HTML 코드를 만들어줘. canvas를 화면 크기에 맞추고 WebGL2가 지원되지 않을 경우 안내 메시지를 표시해줘."

Copilot이 생성한 코드에서 배경색과 화면 크기 관련 부분을 직접 수정하였다.

## 검증 결과

### 1. clearColor 색상 실험
예상: `gl.clearColor(1.0, 0.5, 0.0, 1.0)`은 주황색 계열의 배경이 될 것이다.

결과: 예상대로 주황색 계열의 화면이 나타났다.

이유: `clearColor`의 네 값은 각각 R, G, B, A 값을 의미하며 각 값은 0~1 범위이다. 따라서 R=1.0, G=0.5, B=0.0이면 주황색 계열이 된다.

### 2. resize() 제거 실험
예상: 브라우저 창의 크기를 변경하면 canvas의 실제 렌더링 영역이 창 크기와 제대로 맞지 않을 것이다.

결과: 브라우저 창 크기를 변경했을 때 화면과 canvas의 크기가 제대로 맞지 않는 것을 확인하였다.

이유: `resize()` 함수가 canvas의 실제 크기를 브라우저의 크기에 맞게 다시 설정하고 WebGL viewport도 변경하기 때문이다.

### 3. webgl2 → webgl 실험
예상: `webgl2`를 `webgl`로 변경하면 WebGL1 컨텍스트가 생성될 수 있지만, 이 코드가 사용하는 WebGL2 환경과는 차이가 생길 것이다.

결과: 콘솔에서 WebGL 컨텍스트와 관련된 차이를 확인하였다.

이유: `webgl2`와 `webgl`은 서로 다른 그래픽스 API 컨텍스트이며 지원하는 기능도 다르다.
